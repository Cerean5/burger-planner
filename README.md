# Burger Planner
**Vegan Recipes • Meal Planning • Smoothies • Salads**
Burger Planner helps people discover plant-based burger recipes, explore smoothie and salad ideas, and organize meals for the week.
## Features
- Vegan burger recipe collection
- Search and category filters
- Weekly meal planning
- Smoothie recipes and ideas
- Fresh vegan salad ideas
- Mobile-friendly design
- Installable Progressive Web App (PWA) foundation
- Offline caching support
- Local browser storage for meal plans

## Run Locally

Open `index.html` through a local web server for the best experience.

## Publish for Free with GitHub Pages

1. Open repository Settings.
2. Select Pages.
3. Under Build and deployment, select Deploy from a branch.
4. Select the `main` branch.
5. Select the `/ (root)` folder.
6. Click Save.

GitHub will provide the published website address after deployment completes.

## Storage and Privacy

Meal plans are stored locally in the visitor's browser. The current static version does not provide online accounts or cross-device synchronization.

Do not enter private or sensitive information into this website.

## Important

GitHub Pages supports static websites. Features requiring a server, including user accounts, subscription payments, cloud storage, and protected downloads, need additional backend services.
